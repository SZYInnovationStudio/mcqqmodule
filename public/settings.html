不会填？看教程
1 · Minecraft 服务器

游戏地址和端口用于 MOTD 查询。QQ → MC 消息由 RCON 发送；MC → QQ 消息由 MCSManager 控制台输出读取。

2 · RCON

让平台向 MC 服务器发绑定命令。需要先在 MC 服务端开启 RCON。

3 · QQ 官方机器人

到 QQ 开放平台创建机器人，填写 AppID 和 AppSecret。机器人从群消息取得 OpenID；用户会自行填写数字 QQ 号并二次确认。

不知道群 OpenID？先保存 AppID 和 AppSecret，让机器人在群里收到一条 @消息，再到总览“操作记录”复制发现的群 OpenID。

4 · 独立聊天插件

先把 JAR 安装到 Paper / Purpur 服务器。插件主动连接本平台，QQ → MC 和 MC → QQ 都走插件；AQQBot 白名单命令仍保留 RCON。没装好前保持“原有方式”，不会中断当前聊天。

把生成的 Key 同时填进 MC 服务器 plugins/SZYDMCChatBridge/config.yml 的 key。

5 · 聊天互通

两个方向独立控制，保存后生效。本平台不会修改服务器里的 AQQBot 配置或消息模板；若 AQQBot 自身也在转发聊天，请服主自行关闭它的对应方向，避免重复消息。

官方 Bot 只提供群 OpenID 与发送者昵称，不直接提供群名称或群名片。群 OpenID 可从“允许使用的群”复制；成员 OpenID 首次发言后可从总览操作记录查到。未填映射时显示“QQ群”和 Bot 昵称。QQ → MC 模板支持 &a、&r、${groupName}、${userName}、${message}、${groupId}。开关不影响绑定、/motd、/list。

6 · MCSManager API（仅原有方式使用）

填写面板 API 资料后，点下方“测试 MC 控制台”。只有控制台输出包含玩家聊天，MC → QQ 才能正常转发。API Key 在后台加密保存，页面不会回显；留空保持原值。

参考 官方 API Key 教程与实例 API 文档。不要在聊天中发送 API Key。

填好后点保存，再测试连接。
